# @relayerjs/nestjs-common

Shared utilities for Relayer's NestJS integrations.

This package contains the core building blocks that both `@relayerjs/nestjs-crud` (REST) and `@relayerjs/nestjs-graphql` (GraphQL) rely on.

Not meant to be used directly in most cases. Install the integration package you need (`nestjs-crud` or `nestjs-graphql`) and it will pull this in as a peer dependency.
