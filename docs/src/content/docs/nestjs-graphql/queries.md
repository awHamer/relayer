All queries are auto-generated by `@GqlResolver`. This page shows what each query looks like and how to use it.

## List (cursor pagination)

Default pagination mode. Returns a connection with edges, cursors, and page info.

```graphql
query {
  posts(
    first: 10
    after: "eyJ..."
    where: { published: { eq: true } }
    orderBy: [{ createdAt: desc }]
  ) {
    edges {
      node {
        id
        title
        author {
          fullName
        }
      }
      cursor
    }
    pageInfo {
      hasNextPage
      hasPreviousPage
      startCursor
      endCursor
    }
    totalCount
  }
}
```

**Arguments:**

| Argument  | Type                      | Default | Description               |
| --------- | ------------------------- | ------- | ------------------------- |
| `first`   | `Int`                     | `20`    | Number of items to return |
| `after`   | `String`                  | -       | Cursor from previous page |
| `where`   | `{Entity}WhereInput`      | -       | Filter conditions         |
| `orderBy` | `[{Entity}OrderByInput!]` | -       | Sort order (array)        |

The resolver automatically appends the primary key to `orderBy` for stable cursor pagination. `totalCount` is lazy - the count query only runs if the client selects it.

## List (offset pagination)

Enable with `pagination: 'offset'` or `pagination: 'both'`. When using `'both'`, the offset query gets an `Offset` suffix (e.g. `postsOffset`).

```graphql
query {
  postsOffset(
    limit: 20
    offset: 40
    where: { published: { eq: true } }
    orderBy: [{ createdAt: desc }]
  ) {
    items {
      id
      title
    }
    totalCount
    hasMore
  }
}
```

**Arguments:**

| Argument  | Type                      | Description               |
| --------- | ------------------------- | ------------------------- |
| `limit`   | `Int`                     | Number of items to return |
| `offset`  | `Int`                     | Number of items to skip   |
| `where`   | `{Entity}WhereInput`      | Filter conditions         |
| `orderBy` | `[{Entity}OrderByInput!]` | Sort order (array)        |

`hasMore` is `true` when the number of returned items equals the limit.

## Find by ID

```graphql
query {
  post(id: 1) {
    id
    title
    content
    author {
      id
      fullName
    }
    comments {
      id
      text
    }
  }
}
```

Returns the entity or `null`. Throws `NotFoundException` internally (translated to a GraphQL error) if not found.

## Count

```graphql
query {
  postsCount(where: { published: { eq: true } })
}
```

Returns an integer. Accepts the same `where` input as list queries.

## Aggregate

```graphql
query {
  postsAggregate(
    where: { published: { eq: true } }
    groupBy: ["authorId"]
    _count: true
    _avg: { authorId: true }
    _min: { createdAt: true }
    _max: { createdAt: true }
  ) {
    data
  }
}
```

**Arguments:**

| Argument  | Type                                  | Description               |
| --------- | ------------------------------------- | ------------------------- |
| `where`   | `{Entity}WhereInput`                  | Filter before aggregation |
| `groupBy` | `[String!]`                           | Fields to group by        |
| `_count`  | `Boolean`                             | Include record count      |
| `_sum`    | `{Entity}AggregateNumericFieldsInput` | Sum numeric fields        |
| `_avg`    | `{Entity}AggregateNumericFieldsInput` | Average numeric fields    |
| `_min`    | `{Entity}AggregateAllFieldsInput`     | Minimum across all fields |
| `_max`    | `{Entity}AggregateAllFieldsInput`     | Maximum across all fields |

`_sum` and `_avg` accept only numeric fields. `_min` and `_max` accept all scalar fields.

## Filtering

Filters use the `where` argument with type-safe filter inputs. See [Types](/nestjs-graphql/types/) for all available filter operators.

### Basic filtering

```graphql
query {
  posts(where: { published: { eq: true } }) { ... }
}
```

### Combining filters

```graphql
query {
  posts(where: {
    AND: [
      { title: { contains: "GraphQL", mode: insensitive } }
      { published: { eq: true } }
    ]
  }) { ... }
}
```

### Relation filters

```graphql
# posts that have at least one comment containing "great"
query {
  posts(where: {
    comments: { some: { text: { contains: "great" } } }
  }) { ... }
}

# users with no posts
query {
  users(where: {
    posts: { none: {} }
  }) { ... }
}
```

## Ordering

Sort by multiple fields. Supports nested ordering through one-to-one relations.

```graphql
query {
  posts(orderBy: [{ createdAt: desc }, { title: asc }]) { ... }
}

# nested ordering through relation
query {
  posts(orderBy: [{ author: { lastName: asc } }]) { ... }
}
```
